# Folder Aset Logo Mitra (Partners)

Folder ini khusus untuk menyimpan file logo mitra/klien yang transparan (format PNG/SVG/WebP).

### Cara Penggunaan:
1. Simpan file logo ke folder ini (contoh: `pertamina.png`, `pln.png`, `gasindo.png`).
2. Di halaman Admin Dashboard -> Mitra:
   Masukkan path: `/assets/partners/nama-file.png` (contoh: `/assets/partners/pertamina.png`).
3. Gambar akan langsung dimuat secara tajam dan transparan di website (baik saat development lokal maupun setelah build/upload ke cPanel).
